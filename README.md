# Godot Platformer

The game can be found at https://qubixalyt.itch.io/jumpstart!

theres nothing special, built in two hours following https://jams.hackclub.com/jam/godot-platformer

wasd/arrow keys for controls; there is a unique gravity flip (shift/f/x to flip) feature.

frog + beetle assets from previous leftover personal sprites.

Disclosure: background was drawn using python scripts by AI to simplify asset searching, due to no high-quality ones available on the internet.
